Spring Boot Projects

This repository contains multiple Spring Boot projects.

Projects Included

1. Employee CRUD REST API

- Performs CRUD operations on Employee data
- Uses Spring Boot, JPA

2. SOAP CRUD Web Service

- SOAP based web service for CRUD operations
- Uses Spring Web Services

3. TODO Spring MVC Application
- Built using Spring Boot + Spring MVC
- JSP used as View
- Features:
  - Add Task
  - View Tasks
  - Delete Task
- Uses Controller-Service architecture
- In-memory data storage
